# 独立演示仓库模板

这是公开、无依赖、无凭据的 Go 小项目，不是私有 Fixture 或 Grader。

初始化脚本只会把这四个文件复制到一个新的独立 Git 仓库，不复制 ForgeFlow 的 Git 历史、配置或密钥。

## 待执行的真实任务

修改 `Greet`：先去掉姓名首尾空白；如果为空，返回 `Hello, guest!`；否则沿用 `Hello, <姓名>!`。新增普通姓名、中文姓名、首尾空白和空字符串的测试。

只允许修改 `greeting.go` 和 `greeting_test.go`，不联网、不安装依赖、不访问仓库外文件。使用 `go test ./...` 验证。

当前模板只覆盖原有正常输入。它不是模型已完成上述任务的证据；真实调用需另行授权，执行环境还必须提供 Go。

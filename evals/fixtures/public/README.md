# ForgeFlow software/v1 fixture

This repository is generated from the reviewed public fixture template. Each
`software-v1/<case-id>` tag identifies the immutable starting commit for one
Eval case. `CASE.json` contains only the public task contract; hidden tests and
golden implementations are maintained in a separate private grader repository.

The fixture repository never contains credentials, user data, model evidence,
or hidden grader source.

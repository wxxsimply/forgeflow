# 镜像漏洞风险接受记录模板

> 仅当阶段 9 的镜像扫描出现无法在当前发布窗口修复的 High/Critical 发现时使用。默认决定是阻断发布；填写本模板不等于自动批准。

- Release：
- Git commit：
- 镜像名称与 digest：
- 扫描器及版本：
- 扫描报告路径：
- 申请人：
- 审批人：
- 审批时间（UTC）：
- 到期时间（UTC）：

## 漏洞与可达性

- CVE/公告编号：
- 严重级别：
- 受影响组件与版本：
- 运行时是否可达及证据：
- 是否存在公开利用：
- ForgeFlow 暴露面：

## 缓解和修复

- 当前缓解措施：
- 剩余风险：
- 修复负责人：
- 修复 Issue：
- 最迟修复版本和日期：
- 回滚触发条件：

## 决策

- [ ] REJECTED：阻断本次发布。
- [ ] ACCEPTED TEMPORARILY：在到期日前临时接受。

审批人必须手动签署。接受记录应保存为脱敏发布证据，并在 Release manifest 的 `riskAcceptances` 中关联镜像名称和记录路径。

# 离线补丁审查：先看改动，再批准测试

本工具用于阶段 D 的准备工作，不会调用 DeepSeek、读取 API Key 或更新网站。它不是完整的 Agent 执行入口。

## 1. 提案是什么

提案是 UTF-8 JSON，不是 shell 脚本，也不是直接执行的 Git patch。它只包含以下五个字段：

- `schemaVersion`：固定为 `forgeflow.demo.patch/v1`。
- `taskId`：由操作者为任务指定的 32 位小写十六进制编号。
- `taskSha256`：已审阅任务正文的原始字节 SHA-256；换行变化也会改变摘要。
- `baseSnapshotSha256`：原始四文件经预检返回的 `snapshotSha256`。
- `files`：以 `greeting.go`、`greeting_test.go` 为键，以修改后的完整文件文本为值；至少有一个实际改动。

任务编号和正文摘要还必须通过命令行独立传入并匹配，不接受模型在 JSON 中自行加一个“已批准”字段。工具不读取任务正文，也不验证身份；操作者必须自己核对编号与正文的对应关系。

提案原始 JSON 最多 1 MiB（留出 JSON 转义空间），修改后的完整四文件快照最多 128 KiB。禁止修改 `go.mod`、`README.md`，禁止新增文件、目录、链接、删除或重命名。源码只接受 UTF-8 文本。

## 2. 先只读审查

在项目根目录运行下面的命令；尖括号内容需要替换，不要原样执行：

```powershell
python -B scripts/preview_demo_patch.py --proposal "<受控目录中的proposal.json>" --task-id "<32位任务编号>" --task-sha256 "<64位任务摘要>"
```

默认来源为公开的 `examples/preview-demo` 四文件模板。自定义 `--source` 也必须是受控的平铺四文件目录，不能包含 `.git`，不要指向完整 ForgeFlow 仓库或线上仓库。

输出中的 `diff` 用来逐行检查变动，`approvalSha256` 是本次批准所对应的内容摘要。JSON 会转义终端控制字符，避免模型代码直接发出终端控制指令。只读成功的 `checksPassed:true` 不表示代码编译或测试通过。

提案和差异可能包含源码。保存在私有、受控目录，不上传公共 PR 或普通日志；这里的白名单不是秘密扫描器。不要把私有代码或密钥放入这四个模板文件。目录不能由不可信用户并发修改，路径检查不是完整的恶意文件系统隔离。

## 3. 人工批准后测试独立副本

读完差异，确认仅包含预期逻辑与测试，没有危险代码、删掉断言或伪造测试，再手动执行：

```powershell
python -B scripts/preview_demo_patch.py --proposal "<同一提案文件>" --task-id "<同一任务编号>" --task-sha256 "<同一任务摘要>" --sandbox --approve-sha256 "<刚才审阅的approvalSha256>"
```

不要编写“自动提取摘要再批准”的脚本代替人工审查。摘要绑定整个原始快照、候选快照与任务身份；其中任何内容变化都需要重新审查。

默认使用本地已缓存、事先信任的 `golang:1.22-alpine`，不会拉取镜像。沙箱沿用预检工具的固定测试命令、无网络、非 root、只读挂载、资源限制、总时限和按归属清理。默认 90 秒，`--timeout-seconds` 范围 1～120 秒，另预留清理时间。原始目录不写入，候选只在内存及一次性副本中使用，不执行宿主机命令。

容器隔离不是绝对安全保证，Docker daemon 和镜像必须受信任。批准的是代码内容，不是任意镜像；不要把不可信镜像传给 `--image`。密钥、其他项目和 Docker socket 不挂载进测试容器。

输出含 `sandboxAttempted`（已进入沙箱调用）和 `sandboxExecuted`（沙箱返回测试结果）；超时/清理异常不能算通过。`cleanup_unconfirmed` 时只核查输出的本次容器，不运行全局容器清理。测试退出零也不证明新需求已经实现，需要独立验收；模型可以修改测试，不能只相信模型自带的断言。

## 4. 本轮验证和剩余边界

快速检查命令：

```powershell
python -B -m unittest discover -s scripts -p 'test_preview_demo_*.py' -v
```

本轮共运行 56 项离线测试，55 项通过、1 项因 Windows 未授予符号链接创建权限而跳过，耗时约 1.51 秒。其中新增补丁测试 19 项，包含不依赖符号链接权限的 reparse 拒绝检查；真实符号链接用例仍需 Linux CI 确认。测试提案仅为注释改动，沙箱为 Fake，不是模型生成结果，不运行候选代码。本轮不改模板、不产生模型费用、不更新服务器。真实 Docker 候选集成测试仍待后续执行。

批准摘要不是签名，不防本地用户伪造，不负责一次性消费或持久化；此命令也没有保存完整执行证据或把预算账本接到请求上。后续需把授权、唯一任务目录、账本、提案和测试证据统一绑定，再单独确认真实付费调用范围。不能因此将阶段 D 或网页真实执行标记完成。

# 个人预览端到端人工验收

> 状态：PERSONAL-007 的仓库实现与自动化回归已就绪；当前候选版本尚未完成真实用户验收。本文件是操作清单，不是验收通过证明。

## 前置条件与停止边界

1. 先确认 Go verification、PostgreSQL integration、validate、Web verification 均为绿色，再合并本轮 PR。从合并后的干净 main 记录完整 40 位 SHA；任何后续代码、配置或镜像变化均需重新确定候选。
2. 按 [个人预览边界](personal-preview-scope.md) 仅使用受控仓库、非敏感数据、受邀账号以及 Planning/Mock 配置。不要为本验收输入模型密钥、触发付费调用或运行不可信仓库代码。
3. 由所有者另行授权部署同一候选至真实 HTTPS 预览环境。核对健康检查、发布版本记录与部署镜像的完整 SHA；版本不一致或证书告警即停止。部署、真实备份恢复与回滚分别依照各自手册另行执行，不因本文件获得授权。
4. 至少一名真实测试者在浏览器完成下列流程。2026-09-17 首次回报及 2026-09-18 再次确认的旧演示结果没有本候选 SHA，不能代替本轮验收。
5. 截图、日志、受邀者身份、真实地址、私有仓库信息和运行 ID 只保存在被 Git 忽略的 `.forgeflow/personal-preview/acceptance/` 或其他受控私有位置；PR 只写脱敏结果和证据位置，不上传原件。

## 人工路径

所有路径都必须记录候选 SHA、日期、测试者代号和实际结果；失败写明可复现步骤，不得自动勾选为通过。

| 编号 | 操作与预期 |
|---|---|
| A1 | 通过无证书警告的 HTTPS 登录；能辨认产品用途、预览范围、仓库选择与下一步。如测试者仍不清楚平台功能，记录原话和首次卡住的页面。 |
| A2 | 选择受控仓库，填写非敏感任务，创建 Run；刷新页面后 Run 详情与状态可恢复，不能重复创建。 |
| A3 | 在一条 Run 中批准待处理审批；核对最终状态、报告及相关证据入口。 |
| A4 | 在另一条 Run 中拒绝审批；核对审批为 rejected、Run 为 cancelled，刷新后仍如此。不能对同一条 Run 同时批准和拒绝。 |
| A5 | 退出登录后直接访问先前 Run、审批和 Artifact URL；应要求重新登录或拒绝访问，不得显示原用户数据。使用第二个受邀账号时，确认不能读取第一个账号的资源。 |
| A6 | 提交无效输入并确认提示可理解、无内部路径或密钥泄露。网络故障或超时仅在有安全可控的注入方式时人工测试；否则如实记录“未测”，以自动化故障用例为补充，不能声称真实环境通过。 |
| A7 | 若当前模式确实生成持久化 Artifact，从“产物与差异”下载并核对内容、归属和访问保护；若 Planning/Mock 没有产物，记录“不适用：无真实产物”，阶段 C 的 Artifact 下载项保持未验收，不得伪造产物。 |

发生越权、密钥泄露、数据损坏、不可停止的费用、候选不一致或严重浏览器错误时立即停止并记录 NO-GO。页面文案理解障碍属于待处理的产品反馈，不应被自动化用例掩盖。

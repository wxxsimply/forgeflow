# ForgeFlow 服务条款（上线前草案）

> 本草案不是已生效合同。Production 上线前必须由运营主体根据实际服务地区、收费方式、支持承诺、责任限制和适用法律完成审阅并取得用户有效接受。

ForgeFlow 提供受控的软件工程 Agent、审批、测试和报告能力。模型输出可能不完整或错误，用户必须在合并、部署或用于关键业务前人工审查。服务不自动获得用户仓库、基础设施或第三方系统的超范围授权。

用户应只提交其有权处理的代码和数据，不得提交恶意软件、窃取的凭据、违法内容、未经授权的个人数据或要求绕过安全/审批门禁的任务。用户负责仓库许可证、第三方依赖和最终交付的适用性。

运营方可为安全、容量、法律或费用原因限制、暂停或拒绝 Run，并保留必要审计。任何自动预算、测试、Reviewer 或 Security 结果都不能替代用户对最终变更的责任。未经明确书面约定，预发布版本不提供 Production 可用性保证。

账号凭据不得共享；管理员操作应启用 MFA。发现漏洞或凭据泄漏时，用户应通过 `SECURITY.md` 所述私有渠道报告，不得在公开 Issue 发布敏感复现。

正式版本必须补充：运营主体、服务/付费计划、SLA 与支持、知识产权和反馈授权、保密、暂停/终止、数据导出与删除、担保免责声明、责任限制、赔偿、适用法律/争议解决、出口/制裁、条款变更和生效日期。
